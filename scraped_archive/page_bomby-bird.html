Bomby Bird

2023-2024

To get familiar with the world of coding, I created my own spin on the classic game Flappy Bird, which I named "Bomby Bird."
My Role For this personal learning project, I was responsible for both writing the code (to understand the basics of game mechanics) and designing the custom digital illustrations and character models.
The Concept The main goal of this project was educational: stepping out of my comfort zone to learn programming. However, rather than using standard placeholder assets, I wanted to give the game its own visual flair. I created custom 2D and 3D illustrations for the main character, a flying bomb that might look very familiar to fans of retro games!
Even though the original game files have been lost to time, these visual assets remain a great reminder of my first steps into coding and game design.
